# Focusmedi (Study Lock)

Study Lock (Focusmedi) — student-focused distraction blocker.

This repository contains a Flutter frontend with Kotlin native modules for Android-specific functionality (Accessibility, Usage Access, foreground services, audio playback, etc.).

This initial commit contains the project scaffold and native skeletons. Implementation will follow through incremental PRs.

See CONTRIBUTING.md and the project board for tasks.
